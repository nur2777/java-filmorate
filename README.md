# java-filmorate
## Схема базы данных для приложения Filmorate.
![Схема базы данных для приложения Filmorate.](/src/main/resources/Filmorate_database.png)

Ниже пояснения к схеме.

### Таблица **Users** 
Хранит данные о пользователях приложения.
Первичный ключ - числовое поле id.

#### Примеры запросов для основных операций
```sql
-- Получение данных конкретного пользователя
SELECT *
  FROM users
 WHERE id = 1
```
```sql
-- Получение списка всех пользователей
SELECT *
  FROM users
```

---
### Таблица **Friends** 
Хранит данные о дружеских связях между пользователями.
Согласно требованиям - дружба должна стать односторонней. 
Теперь, если пользователь отправляет заявку в друзья, он добавляет другого человека в свой список друзей, 
но сам в его список не попадает.
Первичный ключ - составной из двух полей, user_id и friend_id. 

```sql
-- Получение списка рузей у конкретного пользователя
SELECT u.name
  FROM friends f
       JOIN users u on f.friend_id = u.id
 WHERE f.user_id = 123 -- заданный пользователь
```

---
### Таблица **Films** 
Хранит данные о фильмах.
Первичный ключ - числовое поле id.

#### Примеры запросов для основных операций
```sql
-- Получение конкретного фильма
SELECT *
  FROM films
 WHERE id = 1
```
```sql
-- Получение списка всех фильмов
SELECT *
  FROM films
```
```sql
-- Получение списка популярных фильмов
SELECT f.name, COUNT(l.user_id) count_likes
  FROM films f 
       JOIN likes l on f.film_id = l.film_id
 GROUP BY f.name 
 ORDER BY count_likes desc
```
---
### Таблица **Film_Genres** 
Является таблицей связи фильмов и жанров. 
Хранит жанры, которым принадлежат различные фильмы.
Для одного фильма может быть указано несколько жанров.
Одному фильму может быть присвоено несколько жанров.
Одному жанру могут соответствовать несколько разных фильмов.
Первичный ключ - составной из двух полей, film_id и genre_id.

---
### Таблица **Genres**
Таблица со списком жанров
Первичный ключ - числовое поле genre_id.

---
### Таблица **Likes** 
Хранит лайки поставленные фильму пользователями.
Одному фильму могут поставить лайки разные пользователи
Один пользователь может поставить лайки разным фильмам.
Первичный ключ - составной из двух полей, user_id и film_id.

---

### Таблица **MPA_Ratings**
Таблица с возможными рейтингами от ассоциации кинокомпаний MPA
Первичный ключ - числовое поле rating_id.
